# Qoo10 Claim Monitor — 작업 지시·정책 보관

이 저장소는 Qoo10 집계·모니터링·셀러관리 프로젝트의 **작업 지시와 판단 정책 정리본**입니다.
전체 대화 원문이나 실행 가능한 프로젝트 전체 백업이 아닙니다. 정리 기준일: 2026-09-29.

## 문서

- [작업 지침](AGENTS.md): 정책 변경·검증·사용자 판단 보존 규칙
- [누적 판단 정책](policies/REVIEW_GUIDE.md): 로컬 정책 원문 v33 및 관련 과거 기준
- [프로젝트 요구사항](prompts/PROJECT_REQUIREMENTS.md): 대화에서 정한 운영·UI·발신 요구사항
- [정기 집계 프롬프트](prompts/MORNING_COLLECTION.md): 현재 저장된 평일 9시 자동화
- [위클리 변경 요구사항 — 미구현](docs/WEEKLY_PENDING.md)
- [문서 출처·갱신 범위](docs/SOURCES.md)

## 적용 우선순위

1. 사용자의 최신 명시적 지시 및 개별 확정 판단·메모
2. 누적 정책의 최신 관련 조항 (충돌하는 과거 기준보다 우선)
3. 기존의 관련 정책과 주문·카트·작성자·시각·전체 대화 흐름

정책 문서의 과거 기록은 삭제하지 않았습니다. 예전 확신도·수집·집계 설명은 최신 조항과 함께 읽어야 합니다.
특히 금요일 위클리 재조회는 **합의된 새 요구사항이며 아직 코드에 적용하지 않았습니다**.

## 포함하지 않은 자료

원시 수집 데이터, 고객 대화 전체, 스크린샷, 로그인·쿠키·토큰, 발신 실제 기록, 로컬 백업 및 전체 대화 원문은 포함하지 않습니다.
정책 원문에는 주문·카트 등의 사례 식별자가 남아 있으므로 **비공개 저장소에서 관리**합니다.
이 문서를 업로드해도 대시보드 데이터 갱신, 재수집 또는 메시지 발신은 실행되지 않습니다.
